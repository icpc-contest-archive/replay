Every year, the universities and colleges organise programming contests for students. The participants of these contests cooperate in teams of three persons. Each team tries to solve as many problems as possible within 5 hours by writing computer programs. This year, BAPC will take place in Leiden (The Netherlands) on 23 October 2010.

The contests are split up into different rounds, spanning different geographical regions: first the local championships, then the Benelux Algorithm Programming Contest, followed by the North Western European Regional Contest, and finally the World Finals.

Every autumn a Benelux Algorithm Programming Contest is held somewhere in the Benelux. Participation in the Benelux Algorithm Programming Contest is possible for every student from any university from the Benelux.

If you're interested in programming and algorithms, do participate!
