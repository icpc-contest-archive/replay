→ About Contest
This problem set was used in simultaneous online contests: - Maratona de Programação da SBC 2021 - Tercera Fecha Gran Premio de México 2021 - Tercera Fecha Gran Premio de Centroamérica 2021 - Torneo Argentino de Programación 2021 Teams had access to internet and as many computers as they'd like to use. Final results and original problem set / info available on https://scorelatam.naquadah.com.br/subbr-2021/

→ Virtual participation
Virtual contest is a way to take part in past contest, as close as possible to participation on time. It is supported only ICPC mode for virtual contests. If you've seen these problems, a virtual contest is not for you - solve these problems in the archive. If you just want to solve some problem from a contest, a virtual contest is not for you - solve this problem in the archive. Never use someone else's code, read the tutorials or communicate with other person during a virtual contest.
→ Practice?
Want to solve the contest problems after the official contest ends? Just register for practice and you will be able to submit solutions.
