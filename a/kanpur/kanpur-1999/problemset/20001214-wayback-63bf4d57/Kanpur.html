Bank Loan

When a person takes a loan from a bank, he/she has to often pay some fixed monthly installment for a certain number of months. This problem is to determine the interest rate that the loan taker is paying to the bank for the loan.  Assume that the interest accrues monthly.

 

Input to the Program

There is a single line of input containing three positive integers (separated by blanks).

The first integer represents the initial loan amount, the second one represents the monthly installment to be paid, and the third one is the number of months for which the installment is to be paid.

 

Output of the Program

The output should be a single real number representing the monthly interest rate (in percent) for this loan.  An accuracy of 0.1% is satisfactory.

 

Sample Input

1000 100 12

  Output for the Sample Input

 2.9

Counting Triangles

You may have seen puzzles for children in which one is required to count the number of distinct triangles in a given figure.  In this problem, you have to write a program to do precisely that: write a program that accepts a set of n line segments in a plane as input and gives the number of distinct triangles formed by these line segments as output.

 

Input to the program

The first line of input gives the number of line segments (n).  The next n lines specify a line segment each by specifying the coordinates of its end points, i.e., x1, y1, x2, y2  (all integers) where (x1, y1) and (x2, y2) are the coordinates of the end points of the line segment.  The four numbers appear on the same line, separated by blanks.  You can assume that -20 <= x1, y1, x2, y2 <= 20. Further assume that n <= 20.  Also assume that no two line segments can be fully or partially overlapping.  Two lines segments may share an end point but not if they are parallel.

 

Output of the program

The output of the program should just be a single integer that is the number of distinct triangles formed by the given line segments.

 

Sample Input

6

3 1 5 1

3 1 3 2

3 2 4 2

4 2 5 1

3 2 5 1

3 1 4 2

 

Output for the sample input

 8

Area of a Polygon

You are given a simple polygon (one without holes) whose edges are all either vertical or horizontal.  You have to find the area of the polygon.

The polygon is placed in the X-Y cartesian plane, with all the edges parallel to one of the two axes.  It is then specified by giving the coordinates of its  vertices in counter-clockwise order.  The coordinates are all integral (and hence the area of the polygon will also be an integer).

 

Input to the program

The first line of the input specifies the number of vertices (n) of the polygon.  The next n lines of input specify the x and y coordinates of one vertex each of the polygon (both integers and separated by blank).  The vertices are specified in counter-clockwise order.  You may assume that n <= 100.  Further assume that for any vertex (x,y) of the polygon, -200 <= x,y <= 200.  It is implicit that the polygon is closed by drawing an edge from the last vertex to the first vertex.

 

Output of the program

The output should be a single integer that is the area of the given polygon.

 

Sample Input

10

0 0

4 0

4 1

3 1

3 3

2 3

2 2

1 2

1 3

0 3

 

Output for the Sample Input

9

Convoy

 A convoy of vehicles has lined up on a single lane and one-way  street in front of a single lane and one-way bridge over a river. Note that since the street is single lane, no vehicle can overtake any other.  The bridge can sustain a given maximum load. To control the traffic on the bridge, operators are stationed on either end of the bridge.  The convoy of vehicles is to be divided into groups, such that all the vehicles in any group can cross the bridge together. When a group reaches the other side, the operator on that side of the bridge uses a telephone to inform the operator on this side that the next group can start its journey over the bridge. The weight of each vehicle is known. The sum of the weights of the vehicles in any group cannot exceed the maximum  load sustainable by the bridge.  Associated with each vehicle is the maximum speed with which it can travel over the bridge.  The time taken by a group of vehicles is calculated as the time taken by the slowest vehicle in the group to cross the bridge. The problem is to find the minimum amount of time in which the entire convoy can cross the bridge.

 

Input to the Program

The first line of input contains three positive integers (separated by blanks): the first one represents the maximum load that the bridge can sustain (in tonnes); the second one represents the length of the bridge (in kms); and the third one is the number of vehicles (n) in the convoy.  Each of the next n lines of input contains a pair of positive integers, w s (separated by blanks), where w is the weight of the vehicle (in tonnes) and s is the maximum speed (in kmph) with which this vehicle can travel over the bridge.  The weights and speeds of the vehicles are specified in the same order as the order in which the vehicles are queued up.  You can assume that n < 1000.

 

Output of the Program

The output of the program should be a single real number specifying the minimum time in minutes in which the convoy can cross the bridge.

 

Sample Input

100 5 10

40 25

50 20

50 20

70 10

12 50

9 70

49 30

38 25

27 50

19 70

 

Output for the Sample Input

75.0


Crossword Puzzle

In this problem, you have to write a program to solve a crossword puzzle.  However this crossword is simpler than the usual crosswords that one sees in newspapers.  Here the clues only specify the starting position of the words in the puzzle, their orientations (across or down), and the word lengths.  Any word from the dictionary can be used anywhere in the puzzle provided that it has the right length, and that the words that intersect in the puzzle do have the same letter at the appropriate places.  And of course, no word should be used more than once.

Consider the following puzzle, for example. Assume that the rows are numbered 0 to 4 from top to bottom and the columns are numbered 0 to 4 from left to right.  We use (x,y) to denote the position of the letter in the xth column and the yth row of the crossword.

 

In this puzzle, we need to fill in five words:  A word of 4 letters across at position (0,0), a word of 4 letters down at position (0,0), a word of 4 letters down at position (2,0); a word of 3 letters across at position (0,2) and finally a word of 3 letters across at position (2,3).  Any word from the dictionary can be used but no word can be used more than once.  For example, here is one possible solution:

 

(0,0) Across: LATE

(0,0) Down: LIED

(2,0) Down: TELL

(0,2) Across: EEL

(2,3) Across: LOW

 

Input to the Program

The first line of input specifies the name of the file that is to be used as the dictionary.  For your testing, you can use the standard Unix dictionary file /usr/dict/words.

You can assume that this file exists, is readable and contains at most 100000 words, sorted lexicographically, one word per line. The words in the dictionary may have both upper and lower case letters.  For this problem however, case is immaterial.  Assume that no word in the dictionary is more than 20 characters long.

The next line of input contains the number of clues (n).  You can assume that n <= 15.  The next n lines give one clue each.  For each clue, the corresponding input line contains respectively, the column and row positions in the puzzle of the first letter of the word; followed by either the character `A' or the character `D', depending on whether the orientation of the word is across or down; followed by the length of the word.  All the entries on a line are separated by blanks.

 You can make the following further assumptions.

1.    The size of the crossword puzzle is no more than 10 X 10.

2.    All words lie completely within the crossword.

3.    The crossword is solvable using the given dictionary.

 

Output of the Program

  The output should contain n lines giving all the words for the crossword puzzle.  The words should appear one per line and in the same order as their clues appear in the input.  All the letters in every word should be in upper case.  All the words should be from the dictionary file (ignoring case). No word should occur more than once. A large number of solutions may be correct for any given input.  Any of these solutions is acceptable.

 

Sample Input

  For the example crossword shown above, the input would be:

/usr/dict/words

5

0 0 A 4

0 0 D 4

2 0 D 4

0 2 A 3

2 3 A 3

 

A Possible Output for the Sample Input

LATE

LIED

TELL

EEL

LOW

 

Numerical Scrabble

There is an unknown 4 X 4 matrix M, whose elements are all positive integers. You are given the sums of the elements of the four rows, the sums of the elements of the four columns, and the sums of the elements of the two diagonals. In addition, you are given the values at four positions in the matrix, the locations of which are specified in the input.  You have to write a program to find an assignment of positive integral values to the remaining 12 positions of the matrix such that the sum of the rows, columns and the two diagonals of the solution match the corresponding given values.

 

Input to the Program

The input contains 22 positive integers separated by blanks. The first four numbers represent the sum of the entries in the four rows respectively. The next four numbers represent the sum of the entries in the four columns respectively.  The next number represents the sum of the main diagonal, that is,   M[0,0] + M[1,1] + M[2,2] + M[3,3].

The next number (this is the tenth one) represents the sum of the elements in the cross diagonal, that is, M[0,3] + M[1,2] + M[2,1] + M[3,0]. The remainder of the input consists of 12 numbers, divided into four triplets of the form i j k. This means that M[i,j] = k.  You may assume that the sum of any row, diagonal or column is no more than 300.  You can also assume that a solution always exists for the given input.

Output of the Program

The output should consist of the 16 numbers of the matrix written out in a 4 X 4 format.  Note that for a given input, there may be more than one possible solution.  Any of these solutions is acceptable.

Sample Input

130 120 172 140 157 93 144 168 66 195 0 1 15 1 3 49 2 2 16 3 0 33

 A Possible Output for the Sample Input

22  15  28  65

49   1   21  49

53   76 16  27

33   1   79  27

 

Train Shunting

In this problem, you are given the layout of the tracks in a certain railway junction (station). Each segment of the track is numbered.  In addition, it is specified whether it is possible to move from a track numbered i to a track numbered j. A train has to be moved from a given track s to another specified track t. In doing so, it is possible that one might have to reverse the direction of the motion of the train once or more than once.  The problem is to find the minimum number of reversals with which a train can be taken from a source track s to the destination track t.

Example

Consider the simple railroad network shown below.

 

Here there are four tracks numbered 0 to 3.  The train can move from track 0 to track 1, track 0 to track 2, etc.  Note however that the train cannot move from track 1 to track 2 directly.  Also note that if the train traverses the segment 1-0-2 or 2-0-1, its direction needs to be reversed once.  Suppose that the source track is track 1 and the destination track is track 2.  Clearly the minimum number of reversals required to take a train from track 1 to 2 is 1.

 

Input to the Program

The input is specified in three parts. In the first part,  the tracks and their connectivity are specified. In the second part, track segments of the form i j k such that the motion i to j to k necessitates a reversal of the train, are specified. In the third part the source and destination tracks are specified.

The first line of the input specifies the number of tracks n which may be assumed to be no more than 50. These tracks are numbered consecutively from 0 to n-1. The following n lines of input each has the following format. The first number in line i+1 (counted from the beginning of input) (for 0 <= i <= n-1) specifies the number of tracks (k) that are directly connected to track i. Followed by this on the same line are k numbers, which are the track numbers  that are directly connected to track i, i.e., the tracks to which the train can directly move from track i.  All the numbers on a line are separated by blanks.  Assume that if a train can move directly from track i to track j, then it can also move directly from track j to track i.

The next line of the input specifies the number of reversal segments (r).  The following r lines each consists of three numbers i j k (separated by blanks). The triple  i j k means that if the segment i-j-k or the segment k-j-i is traversed by the train, its direction of motion needs to be reversed once.

The last line of the input contains two numbers s and t (separated by blanks). The first number s is the source track and the second number t is the destination track.

 

Output of the Program

The output should be a single number that specifies the minimum number of reversals necessary for a train to move from track s to track t.

Sample Input

For the example described above, the input would be:

4

2 1 2

2 0 3

2 0 3

2 1 2

2

1 0 2

1 3 2

1 2

 

Output for the Sample Input

1

A Game of Strategy

Two players compete in the following game.  There is a pile containing n chips; the first player removes any number of chips except that (s)he cannot take the whole pile.  From then on the players alternate moves, each person removing one or more chips but not more than twice the square of the chips that the preceding player has taken.  The player who removes the last chip wins.  For example, suppose that n=50; player A removes 3 chips; player B may remove up to 18 chips and he takes 4.  There remain 43 chips, player A may take up to 32 chips and he picks 5.  There remain 38 chips; player B may now pick all the chips, he does so and thus wins.

You have to write a program which plays the game described above and plays it optimally.

Input to and Output of the Program

The program is obviously going to be interactive.  Assume that your program always makes the first move.  Initially it gets a line of input which specifies the number of chips (n) that are in the pile to begin with.  You may assume that n <= 5000.  It should then output an integer on a line specifying the number of chips that it chooses to pick.  It will then again get a line of input specifying how many chips the opponent has picked up.  Again it must give out the number of chips picked by it in this turn on a line of output, and so on.  Once  the program determines that either it or its opponent has won, it should terminate without giving any further output.

Note that if your program removes the last chip from the pile, the number of chips removed by it in this move must also be printed just like in the previous moves.

Special Note

Your program will be judged by playing it against another program written by the judges.  Thus its actual opponent in the final run will be another program and not a human.  All this does not affect your program at all except for the following.  When your program will be run by the judges, its standard output and input (which normally are the terminal and the keyboard respectively) will actually be Unix pipes.  Due to this reason, you must carefully note the following directions and strictly adhere to them while writing your program.

   If you are using C or C++ as the programming language and using printf, putchar etc., for output, add the following statement after every output statement:  fflush(stdout);

   If you are using C++ and using cout << ... etc., for output, add the following statement after every output statement: cout.flush();

   If you are using Java, add the following statement after every output statement: System.out.flush();

If you are using Pascal, this note does not apply to you.
