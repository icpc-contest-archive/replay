Problem A: Mysterious Island
Input: island.in

There used to live a wise and highly respectable philosopher with few hundred disciples in a tiny island in the middle of the Atlantic Ocean. They were completely isolated from the rest of the world and hence, they did not know any other language but their own. One day the philosopher found a floating plastic bag containing few pages of an English grammar book. As soon as he realized that he had come upon a new language, he immediately started to teach that to his disciples. Since most of his disciples were enthusiastic about the new language, they started to learn the language. Everyday they submitted hundreds of sentences, formed according to the grammar and using the words available. As the words and the grammar were new to them, they made errors while forming sentences. Shortly the philosopher found difficulties with checking so many sentences a day. The grammar and the words were as follows:

sentence ® noun phrase + transitive verb phrase + noun phrase

sentence ® noun phrase + intransitive verb phrase

noun phrase ® article + adjective + noun

noun phrase ® article + noun

transitive verb phrase ® transitive verb

intransitive verb phrase ® intransitive verb + adverb

intransitive verb phrase ® intransitive verb

article ® a | an | the

adjective ® sleepy | lazy | happy | large | hungry | young | bright | angry | pretty | orange | gray

noun ® tortoise | hare | rabbit | mathematician | musician | ballerina | sonata | atom | electron

transitive verb ® composes | walks | dates

intransitive verb ® sees | thinks | dances | goes | looks

adverb ® quickly | slowly | faster | further | magnificently | better

In this problem it is required to write a program which could help the philosopher. The program needs to read a file containing several lines of text based on the grammar above. Each line represents a sentence. The program prints "Valid" for a correct sentence and "Invalid" otherwise.

Input

The input file will consist of up to 100 lines of text where each line represents a sentence to be checked. A line consisting of just the letter E (no leading blanks) will mark the end of file.

Output

For each sentence print a single line containing the word "Valid" if the sentence is correct or "Invalid" otherwise.

 

 

 

Sample Input

happy hare dances better

the young ballerina dances magnificently

a sleepy sonata sees slowly

E

Output for the Sample Input

Invalid

Valid

Valid

Problem B: Vertex Ranking
Input: vertex.in

A tree T = (V, E) is a connected, acyclic, unordered graph where V is a finite set of objects known as vertices and E is a binary relation on V, i.e. E is a subset of unordered pairs (m, n) such that both m and n are elements of V. Each pair (m, n) is called an edge, whereas a path from vertex m1 to vertex mk is a sequence of vertices <m1, m2, m3,  , mk> such that (mi, mi+1) is an edge for any i from 1 through k- 1. The Figure C.T.1 below is a pictorial representation of a tree with six (6) vertices, denoted by 1, 2, , 6 and with five (5) edges (4, 2), (2, 1), (1,5), (3, 1), and (1, 6). An example of a path from vertex 5 to vertex 6 is the sequence <5, 1, 6> where (1, 5) and (1, 6) are two edges.

 

Figure C.T.1

A vertex-ranking of a tree is the labelling of all the vertices with consecutive positive integers beginning with 1 (one) such that any path between two vertices with the same label i contains at least one vertex with label j such that j > i. Given a tree with less than 51 vertices, you are required to write a program that will find the minimum number of labelling integers required to rank the vertices of the tree.

Input

The input file comprises of several information units. Each unit describes a tree. The first line in each information unit indicates the number of vertices of the tree. The second line is an array of edges where each edge is a pair of positive integers. Any two consecutive information units are separated by at least one blank line.

The input file is terminated with the digit 0 on a line by itself.

Output

For each tree, first print its number (Tree 1, Tree 2, etc.) and then the minimum number of consecutive integers required to rank all the vertices.

Sample Input

15

(1,2),(1,3),(1,4),(2,5),(2,6),(3,7),(3,8),(4,9),(5,10),(5,11),(5,12),(8,13),(9,14),(9,15)

10

(1,2),(2,3),(2,4),(3,5),(3,6),(3,7),(4,8),(4,9),(9,10)

0

Output for the Sample Input

Tree 1

Ranking integers = 4

Tree 2

Ranking integers = 4

Problem C: TV Schedule
Input: tvschdle.in
Mr. I Like TV Program (hereafter called Mr. ILTVP) was one morning very happy simply because he found a web-site which had detailed program schedule for a couple of years of his favorite TV station and he spent only sixty five minutes just to download a 50kb TV schedule file. After initial flurry of happiness Mr. ILTVP became little disappointed when he found that the schedule was given in GMT. Since there is a lag of six (6) hours between GMT and BST (Bangladesh Standard Time), he realized that addition of six hours to each program time would be required to solve this time related problem. Shortly it dawned on him that even mere addition of six hours was not good enough since other considerations have to be taken into account.

In this problem you are required to write a program which converts the given TV schedule from GMT to BST so that Mr. ILTVP can use it satisfactorily.

Input

The input file is a multi-line document. There are only two types of lines: comment lines and schedule lines. Comment lines are for general information and are identified by a % symbol at the first column of each line. Each schedule line is divided into four fields: date, start time, finish time, and program name. The date field comes first, next start time, thereafter finish time and finally program name. These fields are separated exactly by one blank space. The date field is of eleven characters and is formatted as follows: the first two are date of the month, third one is a blank space, fourth through sixth are the name of the month abbreviated with the first three characters, seventh is a blank space, and eighth through eleventh are year written in four digits. The start and finish times are of seven characters each. Times are written as hh:mm followed by either AM or PM. Program names are left flushed in a field of forty characters.

Any two lines may have a blank line in between.

The file is terminated by a single % symbol in the first column of a line.

Output

Output is an exact replica of input, only the times are in BST. Even the comment lines, the blank lines, and the file termination character remain unchanged.

Sample Input

% Main programs in the coming days

% Schedule is subject to change without notice

15 Jan 1999 11:10AM 12:00AM Keep Fit

31 Aug 1999 11:30PM 01:30AM Musicals

31 Dec 1999 08:00PM 11:50PM Year End Concert

%

 

 

Output for the Sample Input

% Main programs in the coming days

% Schedule is subject to change without notice

15 Jan 1999 05:10PM 06:00AM Keep Fit

01 Sep 1999 05:30AM 07:30AM Musicals

01 Jan 2000 02:00AM 05:50AM Year End Concert

%

Problem D: Warships at Bay
Input: warship.in

 

In the Bay of Bengal, there are a number of different sizes of warships of an enemy nation cruising here and there. Each ship at a particular moment of time is located inside an mxn cellular grid, satisfying 0< m,n£ 25. A ship occupies a number of consecutive cells either horizontally or vertically. Thus the position of a ship is indicated by either a horizontal or a vertical block located in our grid. Exactly n number of long distance big guns (Gis) have been installed along the shore facing each column of the grid. These guns are capable of hitting any target in the grid only along a straight line parallel to the vertical border of the grid. Each gun can take only a limited number of shots and this limit, which from henceforth will be called firing capacity and denoted by lower case c, is equal for all the guns. A ship will sink if and only if it is hit by one or more guns and the number of shots equals the number of consecutive cells the ship occupies in the grid. No shot from a gun can pierce through a ship blocking the target line of the gun and can hit a ship at the rear. The target line above can be used to hit the ship behind only when the ship in the front is hit and sunk completely. Be it noticed, that sinking is instantaneous.

 

You are being asked by the Defense Ministry of GOB to write a program that will yield the minimum number of guns that need to be fired to sink all the ships.

Input

The input file comprises of a set of information units regarding the firing capacities, dimensions of grids and locations of warships in the grids. The first line in each information unit contains three integers where the first represents firing capacity c and the following two represent values for m rows and n columns of the particular grid in the information unit. Each of the following lines in the unit indicates the location of a ship in that grid. The location is described by a set of ordered pairs of integers.

To give an example, the following line

(m,k),(m,k+1)

indicates a location comprising of two (2) horizontal consecutive cells (m,k) and (m,k+1) where (m,k) is the intersection cell of the mth row and kth column of the grid and (m,k+1) is the intersection cell of the mth row and (k+1)th column. On the other hand the line below

(m,k),(m+1,k)

points a location comprising of two (2) vertical consecutive cells (m,k) and (m+1,k) where (m,k) is the intersection cell of mth row and kth column and (m+1,k) is the intersection cell of (m+1)th row and kth column of the grid.

The end of the input file is denoted by the upper case E.

Output

The program will print the minimum number of guns required to eliminate all the enemy ships. Given the shooting capacity and the number of guns, if complete elimination turns out impossible then the program has to print "No Solution".

Sample Input

3,11,13

(2,4),(2,5),(2,6),(2,7)

(4,5),(5,5),(6,5)

(5,7),(5,8),(5,9)

(2,11),(2,12)

5,11,13

(2,4),(2,5),(2,6),(2,7)

(4,5),(5,5),(6,5)

(5,7),(5,8),(5,9)

(2,11),(2,12)

E

Output for the Sample Input

Information unit 1

Minimum number of guns = 5

Information unit 2

Minimum number of guns = 3

Problem E: Filling Station
Input: station.in

In an old filling station, there is a tank containing fuel and an attendant with only two jugs of capacity V1 and V2 liters, with no markings on them. She uses them to satisfy a customers demand for fuel, and the quantity demanded is always a positive integer. The only maneuvers she performs to serve her customers are:

    • filling up a jug from the tank
    • emptying a jug into the tank
    • transferring the content of one jug to another until either the pouring jug is emptied completely, or the other jug is filled to the capacity, and
    • pouring from any of the measuring jugs with capacities V1 and V2 into the customers jug.
Being old and not-so-well-versed in techniques of algorithm, she goes by trial and error method and uses different sequences of maneuvers on different occasions to meet the same quantity of demand. Thus she spends different amount of time and effort for the same quantity demanded.

You are required to come up with a program that will provide the old lady an algorithm which will involve minimum number of maneuvers on her behalf in meeting a customers demand and thus minimize her time and effort.

Input

The input file contains several lines of data. Each line consists of three integers where the first and second represent the capacities of V1 and V2 respectively, and the third indicates the quantity demanded by a customer.

The input file is terminated by the upper case E on a line by itself.

Output

For each customer, first print his/her number (Customer 1, Customer 2, etc.) and then indicate the minimum number of maneuvers required to meet the quantity demanded followed by a sequence of maneuvers corresponding to that minimum number. It is assumed that the measuring jugs are empty prior to the beginning of the service and the tank contains enough liquid to satisfy the demand.

For a given triple of V1, V2 and quantity demanded, if there is no solution, then print "No Solution".

 

 

 

 

 

 

 

Sample Input

5 3 4

E

Output for the Sample Input

Customer 1

Minimum number of maneuvers = 7

0 3 0

0 0 3

0 3 3

3 0 3

3 3 3

5 1 3

5 0 4

Problem F: Walk an Equation
Input: equation.in

An m x n table is filled with symbols from the set S = {0, 1, 2, , 9, +, - , *, (, )}, satisfying 3£ m, n£ 8. The symbols 0, 1, 2,  , 9 represent digits, and +, - , and * represent addition, subtraction, and multiplica-tion respectively. The notation ( stands for opening parenthesis and ) for closing one.

You have to trace all possible paths starting from any cell in the first row to any cell in the last row. Any path should yield a valid numeric equation. You are allowed to move only in four primary directions: up, down, left, and right. No diagonal moves are allowed. The numerical contents of adjacent cells along the path may form a number, but that number should not exceed more than four (4) digits. You cannot use any cellular content more than once in an equation.

Input

The input file is terminated by two zeros on a line by itself following the last block.

Output

For each block, first print its number (Table 1, Table 2, etc.) and then all possible equations. Each line should represent a single equation. If no equation could be obtained from a block simply print "No Solution".
